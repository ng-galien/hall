---
title: Le vote en séance
summary: Le pointage par zones, les pouvoirs, le vote nominatif.
order: 4
---

Le vote public se fait par **pointage** : chaque votant est déplacé de la zone
« Votants à pointer » vers l'une des zones Pour, Contre, Abstention ou NPPV (ne
prend pas part au vote).

<Steps>
  <Step title="Pointer les votants">
    Sélection multiple puis glisser-déposer vers une zone, ou clic direct sur la zone. Le raccourci
    « Tous les restants votent pour » solde les votes conformes.
  </Step>
  <Step title="Vérifier les pouvoirs">
    Seuls les présents apparaissent comme votants ; un porteur de pouvoir affiche le badge du
    mandant qu'il représente.
  </Step>
  <Step title="Enregistrer">
    L'enregistrement n'est possible que lorsque tous les votants sont pointés : le vote nominatif
    complet est une exigence réglementaire.
  </Step>
</Steps>

<Callout kind="rule">
  Aucun vote ne peut être enregistré tant qu'un votant reste à pointer. Le résultat conserve le
  détail nominatif, pas seulement les décomptes.
</Callout>

Un vote peut porter sur une délibération, ou directement sur un point d'ordre du
jour sans délibération (l'approbation du procès-verbal, par exemple).
