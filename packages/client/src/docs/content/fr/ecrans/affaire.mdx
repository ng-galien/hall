La page d’une affaire s’ouvre depuis l’[espace de travail](/docs/ecrans/espace-de-travail), l’arborescence du menu, la recherche ou le bouton **Ouvrir l’affaire** d’un point de séance.
Le contenu d’une affaire est décrit dans [Affaires, projets de délibération et questions ouvertes](/docs/concepts/affaires-projets-et-questions).

## En-tête

| Bouton | Effet |
| --- | --- |
| **Modifier · Objet** | Modifie le titre de l’affaire. |
| **Commissions** | Affiche les commissions associées ; **Rechercher une commission…** en ajoute une, la croix la retire. |
| **Aperçu PDF** | Produit un PDF du rapport, **Sans les documents** ou **Avec les documents PDF référencés**. |
| **Épingler** | Ajoute l’affaire à la rangée des épinglés. |
| **Voir les modifications** | Ouvre l’historique des modifications de l’affaire. |

## Rapport

Le rapport s’affiche sous l’en-tête, dans l’[éditeur de texte](/docs/ecrans/editeur-de-texte).
Il s’enregistre automatiquement.
**Choisir une photo** et **Prendre une photo** insèrent une image dans le rapport.

## Éléments préparés

La section **Éléments préparés** liste les projets de délibération et les questions ouvertes de l’affaire.
Chaque ligne affiche le titre et, s’il existe, le passage en séance sous la forme « CM numéro · date ».
Un clic sur le passage en séance ouvre la séance.
Un clic sur la ligne affiche le texte de l’élément ; il est modifiable tant qu’il n’est pas verrouillé.

**Nouveau** propose **Projet de délibération** ou **Question ouverte**.
L’élément créé reçoit son propre texte.

L’inscription d’un élément à une séance se fait depuis la fiche de la séance ; voir [Séances](/docs/ecrans/seances).

## Documents

La section **Documents** affiche le nombre de documents joints.
Un clic sur son en-tête la replie ou la déplie.
Les documents sont regroupés par dossier.
Sur chaque ligne, **Ouvrir en plein écran** affiche le document dans la visionneuse et **Ouvrir le document** l’ouvre dans l’espace de travail.
**Supprimer le document** supprime le document lui-même.

**Joindre un document** ouvre un sélecteur :

- **Nouveau document** crée un document dans le dossier de l’affaire et le joint ;
- **Document existant** cherche un document ; chaque résultat affiche son titre, puis son type et son dossier.

Un document du dossier personnel d’un conseiller apparaît avec la mention « Dossier personnel : à reprendre d’abord par le secrétariat » et ne peut pas être joint.

Un fichier déposé dans l’éditeur du rapport devient un document de l’affaire, cité dans le texte à l’endroit du dépôt.

## Export et import

Dans l’espace de travail, le clic droit sur une affaire propose **Exporter l’affaire**.
Hall télécharge une archive d’affaire au format « .hallbundle », avec ses documents.

Le clic droit sur un dossier propose **Importer une affaire**.
La fenêtre demande l’**Archive d’affaire (.hallbundle)**, le **Nom de l’expéditeur** et le **Prénom de l’expéditeur**.
L’affaire est classée dans le dossier « Imports », sous le nom de l’expéditeur.
Une affaire déjà présente n’est pas importée et aucune donnée n’est remplacée.

## Suppression

Le clic droit sur une affaire propose **Supprimer l’affaire**.
Hall demande confirmation ; la suppression est définitive et emporte le rapport.
