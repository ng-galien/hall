## Création et import

![L’écran Tableur de Hall](/app/documentation/captures/ecrans/tableur.png)

**Nouveau tableur**, dans le menu **Nouveau** de l’espace de travail, crée un tableur vide.
**Importer un fichier** avec un fichier CSV ou XLSX crée un tableur à partir de ce fichier.
Un tableur déposé dans un texte peut aussi être inséré comme tableau ; voir [Éditeur de texte](/docs/ecrans/editeur-de-texte).

## Feuille de calcul

Le tableur s’ouvre dans l’espace de travail, sous l’en-tête du document.

| Zone | Usage |
| --- | --- |
| Menu **Démarrer** | Commandes de mise en forme et d’édition. |
| Barre de formule | Affiche et modifie le contenu ou la formule de la cellule sélectionnée. |
| Onglets en bas | Une feuille par onglet ; le bouton **+** ajoute une feuille. |
| Zoom | Le curseur et les boutons **−** et **+** changent l’échelle d’affichage. |

Les cellules se modifient directement.
Le tableur s’enregistre automatiquement.

**Plein écran**, dans l’en-tête du document, agrandit le tableur à toute la fenêtre.
Une plage du tableur peut être incluse dans un texte avec **Inclure une ressource**.
