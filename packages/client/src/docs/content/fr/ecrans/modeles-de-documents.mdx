L’écran **Modèles de documents**, dans le menu Administration, liste les modèles d’après lesquels Hall produit ses documents : la convocation, le message de convocation, le procès-verbal, la délibération et la liste des délibérations examinées. Chaque ligne donne le nom du modèle, son type de document et sa forme, PDF ou message.

![Les modèles de documents d’Alésia](/app/documentation/captures/ecrans/modeles-de-documents.png)

Un clic sur un modèle ouvre sa fiche.
Le **Texte** se modifie dans l’éditeur de Hall, comme un document ; les lignes qui commencent par `::`, comme `::meeting-notice` ou `::minutes{section="facts"}`, marquent l’endroit où Hall place la convocation, les présences ou les points : elles restent dans le texte.
**Choisir une photo**, sous le texte, y place une image ; elle est rangée dans le dossier **Modèles de documents** de l’espace de travail.
L’**En-tête** et le **Pied de page** d’un PDF sont imprimés sur chaque page. **Insérer une image** y place un logo, une image JPEG ou PNG de 60 Ko au plus.
Un message de convocation a un **Objet du message** à la place de l’en-tête.
**Aperçu** montre le modèle tel que Hall l’imprime ; **Enregistrer** le garde. Les documents produits ensuite suivent le modèle enregistré ; ceux déjà produits ne changent pas. La liste des délibérations, qui n’est pas conservée, se produit à chaque ouverture avec le modèle du moment.

![La fiche d’un modèle : en-tête avec logo, texte et pied de page](/app/documentation/captures/ecrans/modele-de-document.png)

**Nouveau modèle** crée le modèle d’un type de document qui n’en a pas encore, avec un texte de départ ; chaque type n’a qu’un modèle.
Les comptes qui modifient l’espace de travail changent les modèles ; les autres les lisent.

Voir aussi [Paramètres de l’application](/docs/ecrans/parametres), pour les données de la commune.
