L’entrée **Paramètres de l’application**, en bas du menu, ouvre l’écran **Paramètres**.
Les sections **Mandature active** et **Lieux des séances** sont réservées aux administrateurs.

![L’écran Paramètres de l’application de Hall](/app/documentation/captures/ecrans/parametres.png)

## Mandature active

**Nombre de conseillers attendu** limite le nombre de mandats en cours.
**Enregistrer** applique la valeur.

## Lieux des séances

La liste contient les lieux proposés pour les séances.
Le premier lieu est proposé par défaut ; il porte la mention « par défaut ».

| Action | Effet |
| --- | --- |
| **Nouveau lieu** puis **Ajouter** | Ajoute un lieu à la fin de la liste. |
| Clic sur le nom | **Renommer** le lieu. |
| **Monter** | Remonte le lieu d’une position. |
| **Retirer** | Retire le lieu de la liste. |

Chaque modification est enregistrée immédiatement.

## Langue et apparence

**Langue** choisit **Français** ou **Anglais** pour l’interface.
**Apparence** choisit **Suivre le système**, **Clair** ou **Sombre** ; le choix s’applique aussi au mode séance.

## Session

**Changer mon mot de passe** demande le mot de passe actuel, puis le nouveau deux fois.
**Se déconnecter** ferme la session.
