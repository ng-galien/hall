L’entrée **Documentation**, en bas du menu, ouvre ce guide sans quitter Hall.

![L’écran Documentation de Hall](/app/documentation/captures/ecrans/documentation.png)

## Sommaire

À gauche, le sommaire liste les rubriques et leurs pages.
La flèche devant une rubrique affiche ses pages.
**Masquer le sommaire** et **Afficher le sommaire** replient ou déplient le sommaire.
**Accueil de la documentation** ouvre la première page.

## Page

Une page affiche son titre, son résumé et son contenu.
**Ouvrir l’écran** ouvre l’écran que la page décrit.
À droite, **Sur cette page** liste les sections ; un clic y conduit.
En bas, **Précédent** et **Suivant** parcourent les pages dans l’ordre du sommaire.

## Recherche

Le champ **Rechercher dans la documentation…** cherche dans les titres, les résumés et le texte des pages.
Les résultats s’affichent avec un extrait ; un clic ouvre la page.
**Entrée** ouvre le premier résultat.

## PDF

**Télécharger en PDF**, dans la barre en haut de la documentation, ouvre la documentation complète en un seul PDF.
Le PDF commence par un sommaire ; chaque ligne du sommaire mène à sa page.
Les pages suivent l’ordre du sommaire de la documentation, chacune sur une nouvelle feuille, avec un numéro de page en pied.
Le PDF peut être enregistré ou imprimé depuis le lecteur PDF.

## Version autonome

La documentation existe aussi sous la forme d’un fichier HTML unique, lisible sans Hall dans un navigateur.
Elle contient les mêmes pages, sans le lien **Ouvrir l’écran**.
Elle est fournie dans une archive avec le PDF ; une fois l’archive décompressée, **Télécharger en PDF**, en haut de la page, ouvre ce PDF.
