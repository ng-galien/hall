Une référence juridique conserve dans l’espace de travail un article du code général des collectivités territoriales (CGCT), tel que publié par Légifrance.

## Création

1. **Nouvelle référence juridique**, dans le menu **Nouveau**, ouvre **Choisir la référence officielle**.
2. **Rechercher dans le CGCT** accepte un numéro d’article ou des mots du texte, à partir de deux caractères.
3. **Rechercher** affiche les **Résultats de la recherche Légifrance**.
4. **Utiliser cette référence** conserve l’article choisi dans le dossier.

## Fiche d’une référence

| Information | Contenu |
| --- | --- |
| **Statut juridique** | En vigueur, Abrogé, Périmé ou Entrée en vigueur différée. |
| **Version officielle** | La version consultée et la version en vigueur. |
| **Validité** | Les dates de début et de fin de validité. |
| **Récupérée auprès de Légifrance** | La date de récupération. |
| **Texte officiel conservé** | Le texte de l’article. |
| **Historique des versions conservées** | Les versions déjà récupérées. |

**Ouvrir sur Légifrance** ouvre l’article sur le site officiel.
**Actualiser depuis Légifrance** récupère la version courante et l’ajoute à l’historique.
« Source vérifiée » ou « Vérification indisponible » indique le résultat du dernier contrôle.

La recherche exige une connexion de Hall à Légifrance.
Sans cette connexion, Hall ne crée pas de nouvelle référence ; les références conservées restent lisibles.
