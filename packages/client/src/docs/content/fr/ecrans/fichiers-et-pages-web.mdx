## Import d’un fichier

![L’écran Fichiers, PDF, images et ressources web de Hall](/app/documentation/captures/ecrans/fichiers-et-pages-web.png)

**Importer un fichier**, dans le menu **Nouveau**, ajoute un fichier au dossier ouvert.
Un fichier peut aussi être glissé depuis l’ordinateur dans le contenu d’un dossier.
Hall conserve le fichier tel quel.

Avant l’import, Hall compare le fichier aux documents existants.
Un fichier identique est signalé par « a un contenu identique à un document déjà présent ».

## Import d’un dossier

**Importer un dossier**, dans le clic droit sur un dossier, importe un dossier de l’ordinateur avec ses sous-dossiers et ses fichiers.

## Document importé

La fiche d’un PDF, d’une image ou d’un fichier texte affiche un aperçu en lecture seule.
**Télécharger** récupère le fichier d’origine.
**Plein écran** ouvre le document dans la visionneuse.
Quand l’aperçu ne peut pas être généré, Hall propose de télécharger le fichier d’origine.

## Visionneuse

La visionneuse affiche un document sur toute la fenêtre.
C’est la même visionneuse partout : espace de travail, page d’une affaire, mode séance, procès-verbaux et délibérations.
**Fermer** revient à l’écran précédent.

## Ressource web

**Nouvelle ressource web** crée une fiche pour une page internet.
**Renseigner la ressource web** demande l’**Adresse web**, au format « https://… ».
**Ouvrir dans un nouvel onglet** ouvre la page.
**Modifier l’adresse** change l’adresse enregistrée.
