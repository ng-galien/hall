Le mode séance occupe tout l'écran : il est fait pour être projeté et suivi en
direct. La séance démarre par **l'appel**, puis déroule les points dans l'ordre
de l'ordre du jour.

<Steps>
  <Step title="Faire l'appel">
    Présences et pouvoirs se saisissent une fois, à l'appel ; le bouton « Présences » permet
    d'ajuster en cours de séance (arrivée tardive, départ).
  </Step>
  <Step title="Dérouler les points">
    Chaque point suit la même séquence : présentation, discussion, vote le cas échéant, clôture,
    point suivant. Les points passés restent consultables.
  </Step>
  <Step title="Voter">
    Le vote se fait par zones : chaque votant est pointé Pour, Contre, Abstention ou NPPV.
    Voir [le vote en séance](/docs/concepts/votes).
  </Step>
</Steps>
