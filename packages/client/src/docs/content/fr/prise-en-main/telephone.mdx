Hall s’utilise dans le navigateur d’un téléphone, à la même adresse que sur un ordinateur.
Les écrans et les droits sont les mêmes.

## Installer Hall comme application

Dans Chrome, Hall peut être installé comme une application, sur un téléphone Android comme sur un ordinateur :

| Appareil | Geste |
| --- | --- |
| Téléphone Android | Menu de Chrome, puis **Installer l’application**. |
| Ordinateur | Icône d’installation à droite de la barre d’adresse, ou menu de Chrome, puis **Installer**. |

L’application apparaît ensuite avec l’icône de Hall parmi les applications de l’appareil.
Elle s’ouvre dans sa propre fenêtre, sans barre d’adresse, avec le même compte et les mêmes écrans.
Chrome propose l’installation seulement si Hall est ouvert à une adresse en `https://`, ou sur l’ordinateur qui l’héberge.

Hall n’enregistre aucune donnée sur l’appareil.
Sans réseau, l’application affiche une page **Hors connexion** ; le bouton **Réessayer** rouvre l’écran dès que le réseau revient.
Après une mise à jour de Hall, l’application installée affiche la nouvelle version à sa prochaine ouverture.

## Menu

Sur un écran étroit, le menu de gauche est masqué.
Le bouton en haut à gauche ouvre le menu par-dessus la page.
Un clic sur une entrée ouvre l’écran derrière le menu.
**Fermer** referme le menu.

## Lecture des pages

Les listes et les fiches s’affichent sur une seule colonne.
Les numéros de téléphone des contacts sont présentés par groupes de chiffres.
Un appui sur un numéro lance l’appel.

## Photos dans un texte

Au-dessus de l’éditeur d’un texte, deux boutons ajoutent une image :

| Bouton | Effet |
| --- | --- |
| **Choisir une photo** | Ouvre la galerie du téléphone pour choisir une image existante. |
| **Prendre une photo** | Ouvre l’appareil photo du téléphone ; la photo prise est insérée. |

Hall accepte les images PNG et JPEG.
L’image est importée puis insérée à la position du curseur.
Les mêmes boutons existent sur un ordinateur ; **Prendre une photo** y ouvre le choix d’un fichier.

L’éditeur de texte est décrit dans [Éditeur de texte](/docs/ecrans/editeur-de-texte).
