Un agent IA connecté par MCP

Un agent d’intelligence artificielle peut rechercher et préparer les documents d’une affaire, ou modifier les modèles autorisés. Le guide hall_learn lui explique Hall sans accès au code source. Les droits de votre compte restent appliqués par le serveur.

Les outils actuels ne conduisent pas les séances, ne votent pas, ne signent pas et n’envoient pas les actes. La commande stdio permet une connexion privée avec votre compte Hall, vérifiée sur macOS. La connexion interactive Windows et un parcours HTTP interopérable restent à fournir ; aucun client de fournisseur IA particulier n’est annoncé compatible. Le guide décrit les étapes et les limites.

  • Versions de Hall Les paquets de chaque version pour Windows, macOS et Linux.
